# Batman Arkham Knight — Original v1

First test build, 2026-10-09. Steam `BatmanAK.exe`, 64-bit. Load a single-player save and enable the required initializer, then one feature at a time. No console commands or popup logging. Do not combine with another table/trainer. Back up your save.

## Included

- Infinite Health: refills living Batman to his current maximum; does not prevent instant/scripted deaths or resurrect him.
- Super Damage (`-`, main keyboard): caps loaded eligible enemy HP at one tenth of maximum. This is effective damage through reduced enemy HP, not an outgoing damage multiplier.
- One-Hit Knockout (`=`, main keyboard): caps those enemies at 1 HP. Mutually exclusive with Super Damage. Gadget knockout behavior is NOT yet verified.
- Extra-Long Grapple and Batarang ranges: raises selected current inventory range fields to at least 50,000 game units. Cannot create targets, bypass visibility, or stream unloaded areas. Original values restored on disable when object identity still matches.
- J saves position, K returns, L undoes/redoes the last teleport.
- F1/F2/F3/F4 teleport up 1/2/5/10 body heights. Walking/falling only, same character/world session, no collision-safe destination checking. Save a safe spot first.

Disable enemy damage cheats during tutorials, scripted encounters, and bosses until tested. Disabling stops edits; it does not restore lost enemy HP. Restart/respawn for a clean comparison. Save/undo positions are forgotten on reinitialization. No armor, no-hit-box, fly, XP, points, combo, global time, puzzle bypass, or Batmobile features.

## Verification

Independently inspected live name registry, current GameEngine -> local player -> controller -> pawn chain, 100/100 player HP, WorldInfo pawn chain, reflected health/position fields, and actual player inventory. Read-only discovery found 174 eligible loaded enemy pawns and 9 inventory gadgets in this session.

The actual embedded Lua initialized against live reads in an API simulation. All game writes were redirected to an in-memory overlay. Tests passed: health refill/off/no resurrection; enemy cap/off/one-hit; grapple and Batarang reflected offsets, range edits and restoration; save/teleport/undo/all upward distances; process-retarget guard. XML, all embedded Lua blocks, and unique record IDs were validated.

These checks are NOT gameplay success reports. Every toggle remains labeled [Test] until the user tests it. Freeze enemies, gadget damage/KO support, challenge features and Batmobile research remain for subsequent versions.

## Development

`work/arkham_knight_runtime.lua` is the original source. `work/build_knight_table.py` builds the CT. `work/test_knight_runtime.py` executes the source with live reads and simulated writes only. Discovery tools are read-only. Module-relative registry/global offsets are build-specific; reflected initializer checks reject incompatible core layouts. No third-party table was imported for Knight.
